# Contributing

## Setup

```bash
pnpm install
pnpm dev
```

## Before opening a PR

```bash
pnpm lint
pnpm build
```

Both must pass — CI runs the same two commands.

## Commit messages

Please follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `chore:`, `docs:`, etc.) — commit history is used to generate release notes.
